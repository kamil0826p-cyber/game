# Male warrior sprite redesign

The previous warrior sheet used a 128x192 atlas: four 32x48 frames for each of four direction rows (south, west, east, north). The replacement keeps that exact contract while introducing eleven distinct dark-fantasy armor silhouettes, readable weapons and shields, directional highlights, layered plate, leather straps and restrained heraldic accents.

All new male warrior sheets preserve transparent backgrounds and the renderer-compatible 128x192 dimensions.
